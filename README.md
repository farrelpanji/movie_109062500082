# Movie Database

Project ini dibuat untuk tugas praktikum Pemrograman Web
menggunakan PHP Native dengan konsep Model View Controller (MVC).

## Teknologi
- PHP Native
- MySQL
- HTML dan CSS
- Laragon

## Fitur
- Menampilkan daftar film
- Menambahkan data film
- Mengedit data film
- Menghapus data film

## Cara Menjalankan
1. Jalankan Laragon.
2. Import database/movie.sql melalui phpMyAdmin.
3. Pastikan konfigurasi database di config/database.php sesuai.
4. Buka http://localhost/mvc_movie_farrel/public/

## Struktur MVC
- Model: mengelola data film dan query database.
- View: menampilkan halaman website.
- Controller: mengatur alur aplikasi dan validasi input.
